# D11: Licenses

Status: accepted

## Decision

The repository and the sets are under MIT. Each set carries its own license file, `LICENSE.md`, and names the license in its manifest. Seeds are MIT-0 and carry no notice.

The decision first named the file `LICENSE`; the rules for sets in `skill-sets/CLAUDE.md` renamed it to `LICENSE.md`.

## Reasons

A set is installed without the root of the repository.

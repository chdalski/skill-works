# D47: One glossary

Status: accepted

## Decision

The terms that skill-works uses, and how it uses them, are in one place: `docs/glossary.md`, in English like everything in the repository. The `CLAUDE.md` refers to it. New terms from decisions go in there before they appear in skills or rules.

## Reasons

So I5 (one term for each thing) stays checkable across files.
